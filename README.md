# PPT Magic · 专业 PPT 制作与汇报设计助手

> 会排版 · 听得懂需求 · 改不坏数据 —— 从"动笔前对齐"到"逐页成稿 + 演讲备注"的完整 PPT 工作流。

做 PPT 最痛的从来不是"画得丑"，而是**方向错了重做、数据被改错、越改越乱**。本 Skill 把专业做法前置：动笔前先用 AI 需求问答把场景、听众、目标、篇幅、风格一次对齐，再按 SLIDE 法逐页成稿，全程用三条质量守则护航。

---

## ✨ 核心亮点

| 亮点 | 解决的问题 |
|------|-----------|
| **阶段 0 · 需求问答对齐** | 拿到一句话就开写、做完整版方向全错的隐性浪费。动笔前 6 必问（场景/听众/目标/篇幅/风格/素材）一次锁死 |
| **联网调研 + 事实卡片** | 最新政策/行业/竞品数据联网补齐，多源交叉、优先权威来源，每个关键数字可溯源 |
| **6 主题 × 13 页型锁定预设** | 视觉只在受控枚举内夹取、永不破版；封面/数据页/时间线/流程图/金句/图文等 13 种页型直接套 |
| **SLIDE 成稿五步法** | Story 主线 → Layout 结构 → Image 视觉 → Decks 成稿 → Echo 备注，逐页产出含演讲词 |
| **三条质量守则（全程刚性）** | ①数据保真：数字/日期/专名一字不改 ②局部精修：指哪改哪、不整页重排 ③先确认后执行：全篇级操作先出影响清单 |
| **交付可编辑 PPTX + 飞书链接** | python-pptx 直接产出可编辑文件，非图片 PDF；一键上传飞书取分享链接 |

## 🚀 快速开始

1. 把本 Skill 安装到支持 Skill 机制的 AI 助手（Claude Code / WorkBuddy 等）。
2. 说一句需求，例如：
   - "帮我做一份 Q3 季度汇报 PPT，10 分钟，给领导讲"
   - "把这份方案做成项目推介 PPT，12 页"
   - "改这份 PPT 的第 3 页，数据更新到最新版"
3. AI 先反问对齐（可跳过，默认走标准设定），随后联网补齐数据 → 按 SLIDE 法逐页产出 → 交付可编辑 PPTX。

## 🛠 技术要点

- **生成可编辑 PPTX**：内置 python-pptx 脚本骨架（封面/章节页/数据页等模板函数），产出 .pptx 而非图片，收下即可改。
- **飞书联动**：生成后一条命令上传飞书文档并取回分享链接，汇报现场直接打开。
- **数据保真工程**：数字指纹比对 + 三级闸门 + 溯源还原，防止 LLM 擅改关键数字。
- **适用边界**：工作汇报、方案推介、培训课件、融资立项、述职、产品发布；重要结论请人工复核。
