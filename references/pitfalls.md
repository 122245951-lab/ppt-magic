# PPT · 常见坑

**阶段 0（前置）**
- 拿到一句话就开写：方向错了返工最大。先反问对齐，给选择题不给填空题。
- 空问"你想怎么做"：澄清问题要带默认推荐项，帮用户决策而非索要信息。
- 缺最新数据就凭记忆写：政策/行业/竞品数据先联网搜证，搜不到标"待核实"，不编造来源与数字。
- 让模型自由发挥配色版式：视觉必须从 6 主题 × 13 页型里夹取，自由 CSS/像素坐标必破版。
- 忽略企业模板：有品牌色/Logo/模板时以企业为准，覆盖一切预设主题。

**交付物（最高频翻车点）**
- 拿 HTML 网页幻灯片/长截图冒充 PPT：最终交付必须是**可编辑 .pptx**（python-pptx 原生元素，非贴图）+ **飞书幻灯片分享链接**，缺一不可。大纲/卡片只是中间产物。
- 整页导出成图片贴进 PPT：不可编辑，不算交付；一切用原生 shape/textbox。
- 只给本地文件、不给飞书链接：必须 `lark-cli drive +import --type slides --as user` 导入并返回 url。
- lark-cli 传绝对路径报 unsafe file path：`--file` 只用 cwd 相对路径，先 cd 到产物目录。
- 飞书导入用错类型：.pptx 只能 `--type slides`（不是 docx）。

**成稿**
- 标题不写结论："营收情况"不如"营收同比增长 34.2%"。
- 一页讲多件事 / 字铺满：一页一核心，单页正文 ≤ 80 字，超了拆页或转图表。
- 字号任意缩：放不下就减字拆页，不缩到看不清；字号只走档位。
- 把话术/方案当承诺：明确辅助属性，重大判断留人工。

**数据保真（最高优先级）**
- 改写把数字抹了："34.2%"写成"约三成多"、日期挪位——汇报/银行场景致命。含数字句零改写。
- 成稿不核对：逐页比对保真清单，防数值漂移与遗漏。
- 外部数据无出处：关键数据在备注/附录附来源。

**修改与操作**
- 改一句却整页重排：局部精修，只动目标，改后回报"其余未动"。
- 换肤/删页/换主线直接做：全篇级操作先出影响清单 + 破坏性标记，确认后执行，保留旧版可回退。
- 覆盖旧版本：每次全篇调整前留底，能"改回刚才那版"。

**方法论沉淀**
- 重复造轮子：同类版式/结构沉淀为模板，别每次从零。
- 自动化未固化：先固化人工流程，再谈自动化。
