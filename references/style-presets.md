# 多模板风格预设（锁定版式库 · 做 PPT 视角）

> 源自蓝图 P2「锁定版式库」：**视觉永远从受控枚举里选，不产生任意值（任意 px / 任意配色 / 任意坐标）。**
> 一句话原则：**"会排版"不是模型发挥好，而是输出空间被约束在专业预设内。风格只许"夹取"，不许"发明"。**

## 一、13 种页型（每页只从这里选）

任何一页都归属下列页型之一，不允许自由拼装的"异形页"：

| 页型 | 用途 | 容量提示 |
|---|---|---|
| cover 封面 | 标题/副题/汇报人/日期 | 1 主标 + 1 副标 |
| section-divider 章节页 | 分隔大章节 | 章节号 + 章节名 |
| bullets 要点页 | 并列要点 | 3–5 条，每条 ≤ 2 行 |
| two-column 双栏对比 | 对比/优劣/前后 | 2 栏，每栏 3–4 点 |
| stat 数据页 | 突出关键指标 | 1–4 个大数字 + 注解 |
| timeline 时间线 | 历程/规划/里程碑 | 4–6 节点 |
| flow 流程页 | 步骤/链路/方法论 | 3–6 步 |
| table 表格页 | 明细/对照 | ≤ 8 行，字要够大 |
| matrix 矩阵页 | 四象限/分类 | 2×2 为主 |
| roadmap 路线图 | 阶段规划 | 近/中/远期 |
| quote 金句页 | 观点/引述/过渡 | 1 句大字 |
| hero 图文页 | 一张主图 + 少量字 | 图占 50%+ |
| closing 结尾页 | 结论/致谢/号召 | 1 句结论 + 行动项 |

**规则**：某页内容塞不进任何页型 → 拆成两页，而不是发明新版式。要 2 栏但当前页型不支持 → 换成 two-column，而不是硬挤。

## 二、6 套预设主题（风格只从这里夹取）

每套主题 = 主色 / 辅色 / 背景 / 字体气质 / 适用场景的**固定组合**，不允许跨主题混搭。

| 主题 | 主色调 | 气质 | 适用场景 |
|---|---|---|---|
| **A 商务蓝** | 深蓝 #1F3A6E + 金灰点缀，白底 | 严谨、可信、稳重 | 工作汇报、述职、政府/银行/国企 |
| **B 科技深色** | 藏青/黑底 + 青蓝高亮，无衬线 | 现代、科技、产品感 | AI/互联网产品发布、技术方案 |
| **C 活力橙红** | 橙 #E8632B + 深灰，浅暖底 | 紧迫、有冲劲、营销感 | 融资路演、营销方案、动员 |
| **D 清新学术** | 墨绿/靛蓝 + 大量留白，衬线标题 | 克制、专业、易读 | 培训课件、研究/教学 |
| **E 高端黑金** | 黑底 + 金 #C9A227，大留白 | 高端、稀缺、品牌感 | 品牌发布、年度盛典、高端提案 |
| **F 极简灰白** | 黑白灰 + 一个强调色 | 干净、聚焦内容 | 咨询风、数据密集型汇报 |

**选主题的默认逻辑**：不确定时 → 银行/国企/汇报用 **A**；AI/科技产品用 **B**；对外路演用 **C 或 E**；培训教学用 **D**；数据多/咨询风用 **F**。企业有品牌色/模板时，**以企业模板为准，覆盖以上全部预设**。

## 三、版式不变量（破版红线）

1. **字号只走档位**：标题/副题/正文/注释四级，不写任意 px；一页放不下 → 减字或拆页，不缩到看不清。
2. **每页一个核心**：一页只讲一件事，标题即结论（"营收同比增长 34.2%"，而非"营收情况"）。
3. **对齐与留白**：元素走网格对齐，页边距统一；宁可留白，不铺满。
4. **配色不超 3 色**：主色 + 辅色 + 强调色，正文一律深灰/黑（浅底）或白（深底）。
5. **图文密度**：单页正文 ≤ 6 行 / ≤ 80 字为上限；超了拆页或转图表。
6. **数据优先可视化**：能上 chart/stat/timeline 就不堆文字表格。

## 四、换风格怎么做

全篇换肤（A→B 等）属于**全篇级操作**：先出"影响清单"（哪些页的深色底/强调色会变），用户确认后整套替换，保持页型与内容不变——**换肤只动 design，不动 content**。详见 `fidelity-and-editing.md`。
