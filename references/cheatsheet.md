# PPT · 速查卡

**一句话总纲**：阶段 0 对齐调研 → SLIDE 法成稿 → 三条守则护航。先对齐后动笔，排版克制，数据保真。

**阶段 0（动笔前不可跳过）**
- 需求问答 6 必问：场景 / 听众 / 目标 / 成功标准 / 篇幅时长 / 风格基调 → 产出「需求对齐卡」
- 联网搜索：补最新政策/行业/竞品数据 → 事实卡片（数值+单位+时间+来源），搜不到标"待核实"
- 风格预设：6 主题 × 13 页型里夹取，有企业模板以企业为准

**6 主题**：A 商务蓝 / B 科技深色 / C 活力橙红 / D 清新学术 / E 高端黑金 / F 极简灰白
**13 页型**：cover / section-divider / bullets / two-column / stat / timeline / flow / table / matrix / roadmap / quote / hero / closing

**SLIDE 法**
- S Story 主线（标题即结论）
- L Layout 结构（章节+每页页型，确认大纲前不出页）
- I Image 视觉（锁定预设，一页一核心，字走档位，配色≤3，单页≤80字）
- D Decks 成稿（数字保真，能图表不堆字）
- E Echo 备注（逐页演讲词，关键数据附来源）

**三条质量守则**
1. 数据保真：数字/日期/专名建清单，含数字句零改写，成稿指纹核对
2. 局部精修：指哪改哪，不整页重排，改后回报"其余未动"
3. 先确认后执行：换肤/删页/合并/换主线先出影响清单，确认后做，留旧版可回退

**开场提示词**：你是企业 PPT 专家。动手前先按阶段 0 反问对齐（场景/听众/目标/篇幅/风格，给推荐项），确认需求卡与大纲后再按 SLIDE 法逐页产出，全程守住数据保真与锁定版式。
