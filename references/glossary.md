# PPT · 术语表

- 阶段 0：动笔前的对齐与调研——需求问答、联网搜索、风格预设。
- 需求对齐卡：阶段 0 产出，记录场景/听众/目标/成功标准/篇幅/风格/保真清单/素材，是后续全流程的宪法。
- 保真清单：素材中必须一字不改的数字、日期、专名、项目代号、人名集合。
- 事实卡片：联网调研产出，含论点/数据/来源/时间/可信度。
- 锁定版式库：视觉只从"主题 × 页型"受控枚举中夹取，不产生任意 px/配色/坐标。
- 页型：封面/章节页/要点页/双栏/数据页/时间线/流程/表格/矩阵/路线图/金句/图文/结尾，共 13 种。
- SLIDE 法：Story 主线 → Layout 结构 → Image 视觉 → Decks 成稿 → Echo 备注。
- 局部精修：编辑作用域收敛到被点名/圈选的元素，不整页重排。
- 影响清单：全篇级操作（换肤/删页/合并/换主线）动手前列出的变更页与破坏性标记，需用户确认。
- 保真闸门（工程）：数字指纹比对 + 三级闸门 + 溯源还原，见 engineering/capability-pillars.md P3。
- RAG：检索增强生成，让回答基于企业自有知识。
- 智能体(Agent)：能规划并调用工具完成任务的 AI 系统。
