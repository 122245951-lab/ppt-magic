# 联网搜索：让 PPT 有据可依

> 阶段 0 的信息增强能力。当素材不足、需要最新数据/政策/行业背景/竞品情况时启用。
> 一句话原则：**结论要有出处，数字要能溯源；搜不到就标注"待核实"，绝不编造。**

## 一、什么时候必须搜

| 触发情形 | 例子 |
|---|---|
| 涉及**最新**政策/标准/法规 | "今年关于数据安全的最新监管要求" |
| 需要**行业数据/市场规模/增速** | "中国 RPA 市场规模、年复合增长率" |
| **竞品/对标**信息 | "某竞品的定价、功能、客户" |
| 引用**时效数据**（当年营收、汇率、排名） | "2026 年 Q2 云厂商市场份额" |
| 专业术语/技术概念需要准确表述 | "RAG / 智能体的标准定义" |
| 用户给了 URL，需读取其中内容 | 产品文档、公告、报告链接 |

## 二、什么时候不用搜

- 用户已提供完整素材和数据（以用户素材为唯一事实源，不擅自联网替换）。
- 纯内部信息（公司内部流程、未公开数据）——搜不到，标注"需内部提供"。
- 方法论、结构、表达类工作（怎么排、怎么讲）不需要联网。

## 三、搜索工作流（5 步）

1. **定检索点**：从需求对齐卡和大纲里列出"需要外部事实支撑的论点"，逐条转成检索词（保留专名/年份/指标，不替换）。
2. **多源交叉**：关键数字至少 2 个独立来源比对；优先官方/权威（政府、统计局、行业报告、公司公告、权威媒体）。
3. **抽取并留痕**：记录每条事实的 **数值 + 单位 + 时间 + 来源**，形成"事实卡片"。
4. **区分时效**：标注数据年份；过时数据明确写"（2024 年数据）"，不冒充最新。
5. **入保真清单**：所有外部数字/日期/专名进入保真清单（见 `fidelity-and-editing.md`），后续改写一字不动，并可在备注/附录列来源。

## 四、事实卡片格式

```
【论点】AI 客服可降低人工成本
【数据】某银行智能客服分流率 68%，人工话务量下降约 40%
【来源】《2025 中国银行业客服中心发展报告》 / 具体 URL
【时间】2025 年
【可信度】高（行业报告）/ 中（媒体引用）/ 待核实
```

## 五、护栏

- **不编造来源、不虚构数字**：搜不到就写"待核实/需内部数据"，不拿模型记忆当事实。
- **官方口径优先**：涉及政策、监管、红线表述，以官方发布为准，不做主观演绎。
- **对外交付物**：关键数据在演讲备注或附录注明出处，重要结论人工复核。
- **URL 读取**：用户给的链接用联网读取工具抽取正文，不凭链接标题猜测内容。
