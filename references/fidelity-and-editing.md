# 数据保真 · 局部精修 · 先确认后执行（做 PPT 质量守则）

> 源自蓝图 P3 保真闸门 / P4 局部精修 / P5 可信操作，转译为"对话式做 PPT"场景可直接遵守的守则。
> 一句话原则：**可改说法，不改数据；改一处不动全篇；全篇大改先出清单再动手。**

## 一、数据保真（最高优先级）

**失败模式**：LLM 改写时把"营收 34.2%"写成"约三成多"、把"2026-09-01 上线"挪成"9 月初"——在汇报/银行/财报场景是致命错误。

**守则**：
1. **建保真清单**：阶段 0 就把素材里的**数字（含百分比/小数/单位）、日期、专有名词、项目代号、人名**全部登记。
2. **含数字句子零改写**：精简/润色/正式化时，遇到含保真项的句子——数字、日期、专名本身一字不动；只可调整周边连接词，且改完必须复核数字仍在。
3. **改完做指纹核对**：成稿后逐页比对保真清单，确认每个数字/日期/专名与素材一致，无遗漏、无数值漂移。
4. **可溯源**：关键数据能指回素材出处或来源链接（配合 `research.md` 的事实卡片）。
5. **宁可保守**：不确定某数字是否可改 → 不改，保留原文并标注。

> 工程实现参考（复刻 AI PPT **产品**时）：`references/engineering/capability-pillars.md` P3 讲指纹抽取 + 三级闸门 + diff 标红 + 一键还原。

## 二、局部精修（指哪改哪，不整页重写）

**失败模式**：用户只想改第 4 页一条要点，结果整页重排，其余内容被无谓改写。

**守则**：
1. **最小作用域**：用户要改某句/某条/某个数字 → 只改那一处，同页其余标题、要点、页脚、版式一律保持不动。
2. **点名定位**：用引用（"把『…』这句"）或序数（"第 3 页第 2 条"）锁定目标，改前复述"我要改的是 X"，避免改错对象。
3. **拒绝整页重生成**：默认不重写整页；确需大改（如换论点）时，先说明会影响哪些内容。
4. **改字号/强调是局部动作**：放大某条、给某词加粗变色，不影响全局样式档。
5. **改完回报**：明确告诉用户"只改了第 N 页第 M 条，其余未动"。

> 工程参考：`references/engineering/local-edit-undo-pattern.md`（元素 content-path 寻址、最小 ops、路径白名单）。

## 三、先确认后执行（全篇级操作）

**失败模式**：换主题/删页/合并章节/转图表直接做，毁了结构才发现方向错了。

**守则**——凡属**全篇级或破坏性操作**，先出"影响清单"，用户确认后再动手：

| 操作类型 | 级别 | 动手前必须 |
|---|---|---|
| 改一个错别字/一句话 | 局部 | 直接改，回报 |
| 换单页版式、转图表 | 单页 | 说明该页变化 |
| **全篇换主题/换配色** | 全篇 | 出影响页清单 → 确认 |
| **删页/合并章节/调顺序** | 结构 | 列删改清单 + 破坏性标记 → 确认 |
| **重写大纲/换主线** | 结构 | 先给新大纲 → 确认后才重排 |
| 生成全新一版 | 全篇 | 保留旧版，不覆盖 |

**影响清单格式**：
```
本次将做全篇级调整，请确认：
- 换主题：商务蓝 → 科技深色，影响全部 12 页配色（内容/页数不变）
- 合并：第 5、6 页 → 1 页 timeline（净减 1 页）
- 删除：原第 9 页"风险预案"（如仍需要请告知）
确认后执行；可随时回退到当前版本。
```

## 四、可回退

- 每次全篇级调整前，保留上一版（大纲/成稿），不直接覆盖。
- 用户说"改回刚才那版"时能还原。
- 手动编辑与 AI 修改交替时，以用户最新版本为准，不擅自回退。

> 工程参考：`references/engineering/local-edit-undo-pattern.md` 第四节统一可逆时间线（forward/inverse ops、多步撤销必须排除已撤销行）。
